場面二 あおぞら図書館の書棚

名前を呼んだとたん、景色が切りかわった。ほこりっぽい閲覧室。書棚には、背表紙の文字が消えかけた本ばかりが並んでいる。一冊だけ、まだ読める本があった。

背表紙を押すと、本がひらきます。

指環

江戸川乱歩

本をひらいています……

本文は青空文庫のテキストから、ルビと注記を取り除いて表示しています。出典はページのいちばん下にあります。

場面三 開札口

扉の向こうは、なぜか古い駅の構内だった。改札ではなく、開札口と書かれた札。鉄の柵には、四けたの数字をあわせる錠がかかっている。錠の横に、色あせた貼り紙がある。

開札口の暗証番号

『指環』の本文を読めば、四つの数がわかる。上から順に並べること。(本はもう一度ひらけます)

  1. 興奮した人たちがドヤドヤと入ってきたのは、何等車の方から？
  2. Ｂが窓から投げた蜜柑は、いくつ？
  3. Ｂの最後のセリフで、笑い声の「ハ」はいくつ並んでいる？
  4. 車掌は「□の中から耳の穴まで」検べた。□に入る漢字の画数は？ (この札の「開札口」にも、同じ字がある)

場面四 開札口を出る

カチリ、と錠がはずれた。柵を押して、開札口を出る。その瞬間、腰に下げた煙草入れが、さっきより少しだけ重くなった気がした。

ダイヤの指環が出てきた。

あの汽車の男が、こっそり「しのばせて置いた」場所。開札口を出るときに取り戻されるはずだった指環は、なぜか、まだここにある。

見上げると、夜空のどこかで、小さな衛星が光った。
