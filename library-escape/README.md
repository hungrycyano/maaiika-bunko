# 図書館からの最後の通信(謎解き脱出ゲーム)

人工衛星が拾った、古い図書館の最後の通信から始まる、1ページ完結の短い謎解きゲームです。
江戸川乱歩『指環』(青空文庫)を読みながら進みます。

- 公開URL:`https://ユーザー名.github.io/maaiika-bunko/library-escape/`
- 本文はリポジトリのいちばん上にある `yubiwa.txt` を読みこみ、ルビ《》・｜・注記［＃］を取り除いて表示します。
  (`yubiwa.txt` を消したり移動したりすると、本が読めなくなります)

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | ゲームの画面・衛星の投稿・貼り紙・青空文庫のクレジット |
| `style.css` | デザイン |
| `game.js` | 答え合わせとヒント、場面の切りかえ |
| `text.js` | `yubiwa.txt` を表示用に整えるプログラム |
| `check-answers.js` | 謎の答えが本文から導けるかの確認用(`node library-escape/check-answers.js`) |

## 小説ページからリンクする

作品ページ(`index.html`)のお知らせやおすすめなど、好きな場所に次の1行を貼ります。

```html
<a href="library-escape/">謎解きゲーム「図書館からの最後の通信」</a>
```

例:お知らせに足す場合

```html
<li><time datetime="2026-10-05">2026.10.05</time><a href="library-escape/">謎解きゲーム「図書館からの最後の通信」</a>をひらきました。</li>
```

ゲームの上にある「← まあいいか文庫へ戻る」から、作品ページに戻れます。
